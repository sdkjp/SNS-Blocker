Focus Blocker — 導入手順（Mac / Safari 用）
==========================================

X（旧Twitter）・Instagram・YouTube の「おすすめ」表示や
無限スクロール、広告・おすすめアカウントなどを抑えて、
フォロー中の投稿・登録チャンネルに集中しやすくする拡張です。

ダウンロード：https://github.com/sdkjp/SNS-Blocker/archive/refs/heads/main.zip

■ 導入（5分・無料・Xcode不要）
------------------------------------------
1) App Store で「Userscripts」(無料) をインストール
   https://apps.apple.com/app/userscripts/id1463298887

2) Safariで X、Instagram、YouTubeを開く →設定(⌘,) →「拡張機能」タブ で
   「Userscripts」に✔チェックを入れて有効化
   （X / Instagram / YouTube へのアクセスを「許可」）

4) Safari ツールバーの Userscripts アイコン(</>）をクリック →
   歯車(設定) → 「Userscripts Directory」で保存フォルダを選ぶ
   （どこでもOK。例: 書類フォルダに「Userscripts」フォルダを作って選択）

5) 同梱の「focus-blocker.user.js」を、その選んだフォルダに入れる
   （ドラッグ＆ドロップでOK）

6) X / Instagram / YouTube を開いて再読込(⌘R)。
   Userscripts アイコンにスクリプトが表示され、ONになっていれば完了。


■ 何が変わる？（既定）
------------------------------------------
・X … 「おすすめ」タブを隠し「フォロー中」に固定／右サイドバー(トレンド等)を非表示
      ／左メニューの不要項目を整理／Explore は「トレンド」に転送
・Instagram … おすすめ投稿・おすすめ動画・おすすめアカウント・広告を非表示
      （フォロー中の投稿は見える）／発見・リールをブロック
・YouTube … ホームのおすすめ・ショート・関連動画・終了画面を非表示
      ／ホームは登録チャンネルに転送
・共通 … 一定回数スクロールすると「休憩しよう」の停止画面（既定30分でリセット）


■ 強すぎる/弱すぎるとき
------------------------------------------
・このファイル冒頭の「FB.DEFAULTS = { … }」の true/false を書き換えると挙動を変えられます。
  例: X を「フォロー中」ではなく普通に戻したい → hideForYou を false に。
  例: もっと強くしたい（Xをブックマークだけ / IGをDMだけ）→ focusMode を true に。
・書き換えたら保存して Safari を再読込すれば反映されます。


うまく動かない・特定の「おすすめ」が消えない等があれば、
その画面のスクリーンショットを共有してください（サイト側の作りが変わると
ラベルやボタンの目印を足すだけで直せます）。
